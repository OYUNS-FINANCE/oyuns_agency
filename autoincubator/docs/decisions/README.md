# Architecture Decision Records

One file per decision, numbered: `0001-checkpointer-and-state.md`, `0002-sse-notification.md`, …

Write an ADR whenever a choice is non-obvious, hard to reverse, or deviates from `docs/SPEC.md`.

## Template
```
# NNNN — <title>
Date: YYYY-MM-DD    Status: proposed | accepted | superseded by NNNN

## Context
What problem, what constraints.

## Options considered
1. ... — pros / cons
2. ... — pros / cons

## Decision
What we chose and why.

## Consequences
What becomes easier, harder, or must be revisited.
```
